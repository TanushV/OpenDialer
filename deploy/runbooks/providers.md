# Provider onboarding

**Telnyx:** Use a separate development account/application. Configure the Call Control connection, webhook URL and Ed25519 public key, authorized owned inventory, destination restrictions, provider spend limits and written traffic approval reference. Create one SIP/WebRTC credential per rep on a credential connection with no outbound voice profile and SIP URI calling set to `internal` (`sip_uri_calling_preference`); the authority reads the connection from the credential's `resource_id` and refuses any other configuration with `TELEPHONY_CREDENTIAL_MISCONFIGURED`. The server creates the agent leg and waits for its signed answered event before readiness. The prospect uses explicit caller ID, link_to, bridge_on_answer, prevent_double_bridge, park_after_unbridge=self and a carrier-side maximum lifetime. Answering-machine detection (`detect_beep` by default) is requested only on the final permitted attempt when voicemail is enabled; a human is still bridged on answer. A dial with no carrier reference after 120 seconds becomes `DIAL_UNCONFIRMED`: the rep is freed, the prospect stays held, and an operator either attaches the call reference or records `confirm_not_placed` with a reason. Test the observed identity, answer-to-audible-rep delay, NAT/audio/sleep/reconnect and direct-PSTN bypass attempt on each actual platform.

Sync existing numbers and review capacity through Numbers. The current no-subscription policy blocks new rentals and paid reputation enrollment. Quotes are planning information; previously submitted uncertain orders remain available for reconciliation. Configure owned-number identity/routing/registration, test a genuine inbound callback, then approve limited real use before healthy status. Paused outbound numbers retain inbound service. Do not use fake calls or identity churn as warmup.

**Inbound callbacks (current remediation source; not yet a released native update):** In Settings → Inbound callbacks, save an optional business SIP or US phone destination and a 5–30 second ring deadline. Routing selects the responsible rep with recent audio/telephony readiness, then a same-seller available teammate, then the configured business destination. A rep and endpoint are reserved during routing/conversation, so Get next lead cannot start another call. The rep sees a return-call panel with mute and hangup. Missing/ambiguous caller matches do not select an unrelated lead. Exhausted destinations receive a neutral unavailable message and a local review task; this is not a staffed live waiting queue. A transfer acknowledgement alone does not complete the task. A verified bridge to the assigned rep completes the return-call task; a business fallback remains available for human review.

Transfer commands currently use the published PAYG reference of $0.10 per invocation; basic speech uses $0.000009 per character, plus inbound/destination call-leg minutes, rounding and carrier fees. Repeated attempts use the same durable command identity. When the routing budget is exhausted the caller is not transferred or spoken to; the call ends and an ordinary open return-call task remains. Hangup and recovery never depend on budget. Each finished call settles its hold to a labeled estimate (leg and STT minutes × the cost register's rates); an attributable carrier billing import replaces the estimate. See the current [Telnyx price card](https://telnyx.com/pricing/voice-api), [transfer lifecycle](https://developers.telnyx.com/api-reference/call-commands/transfer-call) and [speech contract](https://developers.telnyx.com/api-reference/call-commands/speak-text), checked October 18, 2026. No dashboard view places a paid request.

**Offline local authority remains a deployment gate:** the saved fallback is executed by the authority and cannot run while the laptop is asleep/offline. Configure and test an independently reachable carrier-side failover destination before relying on unattended callbacks. The setup reference is operator-reported, not proof of a working carrier route. Use the existing-host ingress recipe in the deployment runbook for online local operation. Unattended offline callback proof remains M5.09/X01/X07; a webhook failover URL is another receiver, not a telephone destination. Do not enable a charge-bearing SIP-forwarding service as a substitute.

**Registry and consent:** Import only seller-authorized national/state data with an access reference, covered area codes and refreshed timestamp, or configure the documented prepaid screening adapter with seller authorization. Prepaid credits do not waive seller-access requirements. New recurring registry/RND commitments are not activated. Checksums/counts/format are validated before atomic publication. Missing/stale authorized national coverage blocks every US outbound attempt. Internal opt-outs survive imports and backup rollbacks. Use the consent evidence API for separately scoped treatments/revocations; RND result imports require authorized reference-date evidence. Carrier lookup never proves ownership, DNC clearance or consent. Obtain reviewed jurisdiction-specific rules.

**OpenAI API:** Add a project/service-account key on the authority; select evaluated models by role. Responses uses strict structured output, bounded output/deadline and store=false. Company research caches first-party sources with provenance; failures retain an approved fallback, and each lead's paid preparation attempts are bounded with backoff. Provider request IDs and native usage are retained; invoice reconciliation remains separate. (The deferred OpenAI Batch pipeline was removed in 0.3.0; unfinished legacy batches are closed at startup with reason `batch_pipeline_removed` and never resubmitted.)

**OpenAI-compatible endpoint (LiteLLM, OpenRouter or similar):** Select the explicit compatible route and enter its HTTPS base URL or loopback HTTP URL plus optional key. It uses chat/completions with structured JSON. Nothing auto-discovers a local endpoint or sends data to an unconfigured account. Use a model that supports the selected schema contract.

**ChatGPT plan usage (retired):** The per-user ChatGPT-plan OAuth route was removed in 0.3.0. A store that still selects it reports inference as unconfigured with a clear reason; choose API or an OpenAI-compatible endpoint instead.

**Live coaching/STT:** Select OpenRouter and enter its API key plus an evaluated model (default openai/gpt-oss-120b). Cerebras is the only permitted provider, with ZDR, denied data collection and no provider fallbacks. Supported structured output and route receipts are required. A transient refusal, timeout or rate limit stays quiet and shows a calm helper status; cached knowledge is shown only when the helper is unconfigured or its circuit is open. Calling controls remain independent. The live interpreter and ordinary finalizer use the same Cerebras capability. Optional research/script and stronger-review roles remain separately configured. Transcription runs on Telnyx with separate permission and account-retention evidence: one inbound-track stream on the prospect leg and one on the rep's agent leg, so the speaker side comes from the leg (Soniox does not report a track). Verify finality, timing and per-stream charges. Raw content expires locally within five minutes of original receipt; local tests do not certify upstream deletion. Null timestamps/confidence remain null. See the active [remediation plan](../../docs/REMEDIATION_PLAN.md) for remaining replay, privacy and live-provider gates.

**Voicemail:** Only the final permitted submitted attempt is eligible; expired reservations or a reduced policy allowance cannot unlock it early. Publish reviewed human-recorded Telnyx media names and separate prerecorded permission. The message must match the required opt-out wording (digit 9 in this implementation). Test true mailbox/beep readiness and full/no-beep/false-machine failures. Keep the first drop monitored. Detached use additionally requires reviewed topology evidence and a real recovery destination. Playback-start confirmation precedes rep release; number capacity stays leased until terminal completion. Live certification cannot be replaced by simulated success.

## Cost worksheet

Fill this from the selected account's published rate card and actual receipts before authorizing work. Reference prices in the application are dated estimates, not a current invoice. Record currency, unit/rounding, rate, provider/source URL and checked date. Every total separates estimated, held, settled and uncertain amounts; prepaid credit is funding, not a second usage charge.

| Component | Measured units and calculation | Current policy |
| --- | --- | --- |
| Voice | Actual agent and prospect leg billed minutes × each route rate, plus inbound/transfer legs | PAYG; do not count only connected prospect talk |
| Transcription | Engine/track billed minutes × account rate | Requires separate permission and retention acceptance |
| Transfer / TTS / AMD / lookup | Each invocation, character or lookup × configured rate | Optional, explicitly budgeted; lookup is not spam reputation |
| Preparation and search | Input/output tokens and search invocations × configured rates | Bounded advance work; cached facts reused; no live-call research |
| Live helper and claim review | Every actual generation and selective-review request's tokens × actual provider rates | Cerebras-only authorized route; late/discarded requests may still cost money |
| Conversation finalization/review | Each accepted request's measured usage | Shared derived state; no transcript archive |
| National DNC | New/stale authorized prepaid lookup count × unit rate; include minimum top-up separately | Existing credits/source authorization; no new subscription |
| Existing numbers | Existing rental/registration obligations from account statement | Disclosed ongoing cost; new rentals blocked |
| Recording / CRM / calendar / reputation enrollment | Zero application-requested units | Disabled |

For a proposed day, estimate voice/STT from the feasible schedule and observed handling times, then add bounded preparation, helper/review, finalization and screening demand. Show low/expected/high usage instead of claiming a fixed per-call AI price. Add taxes/provider credit fees separately. Compare the estimate with actual receipts after the day; retain unknowns rather than inventing zero charges.
