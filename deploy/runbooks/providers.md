# Provider onboarding

**Telnyx:** Use a separate development account/application. Configure the Call Control connection, webhook URL and Ed25519 public key, authorized owned inventory, destination restrictions, provider spend limits and written traffic approval reference. Create one SIP/WebRTC credential per rep on a credential connection with no outbound voice profile. Backend token issuance verifies this restriction. The server creates the agent leg and waits for its signed answered event before readiness. The prospect uses explicit caller ID, link_to, bridge_on_answer, prevent_double_bridge, park_after_unbridge=self and a carrier-side maximum lifetime. Test the observed identity, answer-to-audible-rep delay, NAT/audio/sleep/reconnect and direct-PSTN bypass attempt on each actual platform.

Sync existing numbers or obtain a fresh quote through Numbers. An explicit approved initial amount and configured monthly procurement ceiling are required; uncertain orders are retained for reconciliation, never blindly repeated. Configure identity/registration, test a genuine inbound callback, then approve limited real use before healthy status. Paused outbound numbers retain inbound service. Do not use fake calls or identity churn as warmup.

**Registry and consent:** Import only seller-authorized national/state data with subscription reference, covered area codes and refreshed timestamp. Checksums/counts/format are validated before atomic publication. Missing or over-31-day required coverage blocks calling. Internal opt-outs survive imports and backup rollbacks. Use the consent evidence API for separately scoped treatments/revocations; authoritative RND result imports require subscription/reference-date evidence. Carrier lookup never proves ownership, DNC clearance or consent. Obtain reviewed jurisdiction-specific rules.

**OpenAI API:** Add a project/service-account key on the authority; select evaluated models by role. Responses uses strict structured output, bounded output/deadline and store=false. Company research caches first-party sources with provenance; failures retain an approved fallback. Deferred script Batch is explicitly API-only and waits for researched packets. Reconciliation joins custom IDs, validates each output and reports only failed/missing objects for retry. Provider request IDs and native usage are retained; invoice reconciliation remains separate.

**LiteLLM:** Select the explicit compatible route and enter its HTTPS base URL or loopback HTTP URL plus optional key. It uses chat/completions with structured JSON. Nothing auto-discovers a local endpoint or sends data to an unconfigured account. Use a model that supports the selected schema contract.

**Official ChatGPT plan usage:** In local mode choose Continue with ChatGPT and complete the official registered OAuth flow in your browser. PKCE, state/nonce, issued client ID, JWKS signature, issuer/audience/identity, expiry and scopes are validated. Tokens are per user, not shared across the tenant. Only eligible public Responses model slugs are used; store=false, stream=true and response.completed are required. Shared-server import requires the documented protected per-user self-hosted registration flow, not a browser cookie. Plan access does not imply Batch support or unlimited capacity.

**Groq/STT:** Add the Groq key/model for tiny validated cards with deadline/cancellation/circuit fallback. No live web search runs in coaching. Soniox transcription starts on the carrier only with explicit permission; Parakeet is a replaceable adapter choice. Verify actual track attribution/finality/timing and dual-track charges before launch. Null timestamps/confidence remain null.

**Voicemail:** Publish reviewed human-recorded Telnyx media names and separate prerecorded permission. The message must match the required opt-out wording (digit 9 in this implementation). Test true mailbox/beep readiness and full/no-beep/false-machine failures. Keep the first drop monitored. Detached use additionally requires reviewed topology evidence and a real recovery destination. Playback-start confirmation precedes rep release; number capacity stays leased until terminal completion. Live certification cannot be replaced by simulated success.
