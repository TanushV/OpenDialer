# Backup, recovery and incident handling

**Backup.** Settings → Operations → Create backup writes a JSON export of the seller's business records (leads, calls, notes, tasks, suppressions, consent, numbers, costs and configuration documents, but not users, passwords, sessions or provider keys) to `<data dir>/backups/<id>.backup`. Set `OPENDIALER_BACKUP_COPY_DIR` to also write a copy to another disk. Copy backups off the host at least daily. Saved credentials are excluded from business exports. To recover encrypted provider settings, preserve `config/` and the original OS credential store (desktop) or deployment encryption key (server) separately. Without that key, re-enter credentials; copying encrypted files to another PC is insufficient. Keep older plaintext backups and imported setup/login files private.

**Restore.** Pause reps first. Restore from Settings or `uv run python deploy/backup/restore.py https://your-host BACKUP_ID` (prompts for an administrator session token). Restore adds records missing from the current store and keeps every current record, carrier reference, human note and later edit. Suppressions and consent revocations in the backup are re-applied if the current copy is weaker. Pending carrier commands become uncertain, every user is paused, and outbound stays blocked (`RESTORE_RECONCILIATION_REQUIRED`) until reconciliation.

**Reconcile.** `POST /v1/admin/restore/reconcile` with a review reference (and, when needed, a map of call IDs to carrier call references). It asks the carrier about every restored live call and finishes those the carrier reports ended. Any call still alive or unverifiable keeps outbound blocked; so does a remaining agent or inbound leg, which you stop or verify in Settings → Recovery.

**Stuck calls.** Settings → Recovery lists uncertain carrier commands, unconfirmed dials, uncertain agent legs and failed jobs. Reconcile with the carrier reference, stop a verified live leg, cancel an intent that was never sent, confirm from the carrier account that an unconfirmed dial was not placed, or retry a failed job. A lost carrier response never triggers a new dial.

**Consent withdrawals.** `POST /v1/admin/consent` with an endpoint, permission list (`live`, `transcription`, `recording`, `prerecorded`, `messaging`), `revoked: true`, an evidence reference and a stable `idempotency_key`. Revoking stops the named permissions on live calls immediately.

**Costs.** Settings → Operations → Provider cost reconciliation imports carrier statements (CSV or JSON, at most 1 MiB / 1,000 records: `provider_record_id`, one of `call_id`/`callback_id`, `cost_usd`, `duration_seconds`) and records credits against settled charges. A call's budget hold settles to a labeled estimate when it ends; statements replace estimates with carrier figures.

**Desktop or VM failure.** Keep the app data and restart the same installation. Carrier time limits bound abandoned legs while the authority is down, and the recovery sweep reconciles commands and active calls on restart.
