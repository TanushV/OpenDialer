# Release and update

Keep the stable identifier `com.opendialer.desktop`. Bump Python, desktop package/lock, Cargo/lock and Tauri versions together. Complete the acceptance matrix and preserve an installed baseline with a human note and suppression. Freeze the backend with `scripts/build_sidecar.py`; the release must not contain a shell wrapper or depend on a source checkout/Python installation.

On macOS, finish with `uv run python scripts/package_macos.py --build` after freezing. It gives only the frozen Python sidecar the documented library-validation exception, re-seals the main bundle without broadening its entitlements, probes the signed backend, recreates the archive/DMG and signs the final bytes with their version. Running `tauri build` alone is not the final macOS release step.

Keep `TAURI_SIGNING_PRIVATE_KEY` and its password outside Git. The repository Actions secret store is configured; the pinned public key is in Tauri config. Build native packages on the corresponding OS. `.app.tar.gz.sig`/Windows/Linux signatures and the updater JSON must refer to the exact uploaded bytes. Publish a reviewed release only after verification; draft CI packages do not update users. The configured latest endpoint requires a published non-prerelease release. Developer previews must clearly disclose missing platform/provider certification.

For macOS public distribution, configure a real Apple Developer ID certificate, hardened runtime entitlements and notarization credentials, then validate a quarantined clean install. Updater integrity signing is separate from Apple trust. Windows signing and Linux WebRTC/headset certification have independent gates. Never claim these are passed because compilation succeeds.

Install once. Thereafter use Settings → App updates, verify the signed offered version, install it in place, quit/reopen, and check the saved workspace IDs, human note, suppressions, database integrity and new version. A failed signature must not replace the app. Do not uninstall/reinstall or reset data for an update.

Release artifacts include checksums, dependency notices, source revision and the acceptance report. Dependency/security CI, code review and reproducible test output accompany each release. Preserve updater key recovery material securely; losing it requires a separately planned trusted rotation, not silently changing the public key.

Windows upgrades must stop the owned frozen runtime before replacing its executable. Updater cleanup calls Tauri cleanup_before_exit and then exits directly, so the runtime cleanup is registered as a resource drop guard as well as a normal exit handler. NSIS preinstall also handles older releases: its embedded script selects only the canonical installed opendialer-backend.exe path, stops those processes, and requires exclusive access before copying. It never deletes application data or kills unrelated executables. The path-isolation PowerShell test and a real signed 0.1.1 baseline upgrade are required; seeing the new desktop executable version alone is insufficient. Preflight must report the new backend version too.

For large Windows artifacts, stage-windows-release.yml can verify and upload the exact successful native build directly to an existing draft. It checks immutable run/source identity, pinned-key signatures, authenticated version, deliberate tamper rejection and saved native acceptance. Reconcile uploaded SHA-256 digests before publishing. This job never rebuilds or publishes a release. Use windows-acceptance.yml with baseline_version to exercise the existing published baseline through the signed updater.

Windows update installation is asynchronous. The acceptance harness must await the scoped updater process exiting and require the installed backend SHA-256 to match the backend extracted from the exact verified NSIS package before relaunching. Use the runner's PowerShell 7 for the completion probe and fail immediately on probe errors. A new GUI ProductVersion alone can appear while backend files are still being copied. Then require actual backend-version preflight, exact saved IDs, the human note and suppression continuity.
