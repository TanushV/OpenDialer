# OpenDialer 0.8.12

- **A more natural callback greeting.** A short, generic message says the person is unavailable and that you'll return the call.

Updating from 0.8.11 keeps your workspace and saved credentials. macOS may ask for microphone access again.
Versions 0.2 and 0.3 start a fresh workspace and old data stays untouched in its previous folder.
Updating from 0.6.0 or 0.6.1 may require you to re-enter keys and re-import setup or login files.
