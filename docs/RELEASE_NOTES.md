# OpenDialer 0.8.10

- **No registration timer for new numbers.** Once a number and workspace pass setup, the number can enter its normal warmup ramp immediately.
- **Return calls reuse the ready microphone.** Answering a return call uses the active rep microphone without asking the operating system to open it a second time.

Updating from 0.8.9 keeps your workspace and saved credentials. macOS may ask for microphone access again.
Versions 0.2 and 0.3 start a fresh workspace and old data stays untouched in its previous folder.
Updating from 0.6.0 or 0.6.1 may require you to re-enter keys and re-import setup or login files.
