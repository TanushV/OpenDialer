# OpenDialer 0.8.11

- **Number orders show current activation.** The order list shows the carrier status from the latest inventory sync and lets you check the order until the number is set up.

Updating from 0.8.10 keeps your workspace and saved credentials. macOS may ask for microphone access again.
Versions 0.2 and 0.3 start a fresh workspace and old data stays untouched in its previous folder.
Updating from 0.6.0 or 0.6.1 may require you to re-enter keys and re-import setup or login files.
