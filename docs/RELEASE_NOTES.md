# OpenDialer 0.8.14

- **Prefer in-state caller IDs.** The Dialer can use an eligible out-of-state number when local capacity is unavailable. Existing caller assignments stay stable, and the capacity plan shows the fallback separately.
- **Stage-aware live guidance.** The live assistant receives the tracked conversation stage and every scripted objection response alongside the prepared script and recent dialogue.

Updating from 0.8.13 keeps your workspace and saved credentials. macOS may ask for microphone access again.
Versions 0.2 and 0.3 start a fresh workspace and old data stays untouched in its previous folder.
Updating from 0.6.0 or 0.6.1 may require you to re-enter keys and re-import setup or login files.
