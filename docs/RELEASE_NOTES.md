# OpenDialer 0.8.13

- **Capacity planning handles inferred time zones.** The report completes when an imported lead has an inferred time zone.
- **Workspace greetings.** Set a missed-call greeting in Callbacks. A blank field uses the standard greeting with the workspace name.

Updating from 0.8.12 keeps your workspace and saved credentials. macOS may ask for microphone access again.
Versions 0.2 and 0.3 start a fresh workspace and old data stays untouched in its previous folder.
Updating from 0.6.0 or 0.6.1 may require you to re-enter keys and re-import setup or login files.
