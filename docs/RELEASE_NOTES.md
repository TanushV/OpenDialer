# OpenDialer 1.0.1

- **Remove lists clearly.** Remove a list from active views and dialing, then restore it through Show removed lists. Find removed contacts in the Removed leads view.
- **Choose a real membership.** Remove from list offers the selected contacts' actual lists, picks the current list when possible and reports the changes it made.
- **Keep shared contacts.** Contacts in another active list stay available. Call history and opt-outs remain, and importing existing contacts no longer conflicts with background preparation.
- **See script refresh progress.** Meaningful script edits automatically rewrite prepared scripts from the current master. Formatting-only edits keep them, and the Script page shows the current version and progress.

Updating from 0.9.x or 0.10.x keeps your workspace and saved credentials. Updating from 1.0.0 also preserves your workspace, numbers, playbook and calling settings. macOS may ask for microphone access again.
Versions 0.2 and 0.3 start a fresh workspace and old data stays untouched in its previous folder.
Updating from 0.6.0 or 0.6.1 may require you to re-enter keys and re-import setup or login files.
