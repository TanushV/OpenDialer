Runtime and acceptance source is `05c08bf6e55f9752275180f3c0b59779c19232de`. Version 0.2.1 adds updater resource cleanup and a path-scoped legacy Windows backend unlock hook. The original specification and [optimization checklist](OPTIMIZATION_PLAN.md) are preserved. The [0.1.1 record](VALIDATION_0.1.1.md) remains available. 0.2.0 Mac local/connected use passed, but its Windows update candidate was withdrawn after a real upgrade retained an old backend. A fresh-install pass is never a substitute for that upgrade gate. The 0.2.1 installed-update gate is pending below.
