# OpenDialer 2.1.0 local verification

| Check | Evidence |
|---|---|
| Shared calling | Disposable PostgreSQL ran the relay migrations. Two local SQLite authorities synced distinct HubSpot fixture segments, placed overlapping Telnyx replay calls from the same caller ID, and each received its own return call and prospect packet. |
| Supabase relay | A disposable local Supabase stack applied the migrations. Two real Auth sessions exercised scoped RPCs through PostgREST. Signed fixture events passed through the Edge receiver and both callbacks reached the right profile at the fixture cap. A transfer event with only the leg ID retained its original profile and context. |
| Sticky caller ID and return routing | A retry and a rep handoff kept the same caller ID. The first pooled reservation preserved an existing desktop's caller ID at the outbound limit. A refused call kept the previous callback owner. A confirmed call changed the owner. The binding retained its owner after old attempt records were removed. Later transfer-leg events went to the same desktop. |
| Capacity | The relay admitted outbound attempt 90 and refused attempt 91 on the same number. A simultaneous reservation for the last slot admitted one rep. Inbound calls still routed at the limit and while outbound was paused. |
| Mac app | The isolated 2.1.0 Tauri bundle started its frozen authority and completed onboarding. The native Dialer opened each rep's matched prospect from the two replay databases. Decline moved the first replay callback to Ending. The browser suite exercises callback arrival while Settings is open. |
| Local checks | The fast and full tiers passed, including the complete WebKit suite, relay migration tests, edge tests and Rust checks. |

The Mac run used disposable profiles and replay events. R12.5 covers the hosted relay migration, Telnyx caller ID from the second application, audio in both directions, background ringing, and carrier behavior while a rep's computer is offline. Live HubSpot test segments and two approved test phones are needed for that run.
