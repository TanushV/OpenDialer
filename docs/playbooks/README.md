# Business knowledge, coaching and evaluation

In the development build, Intelligence → Business knowledge lets an administrator publish the product description, pricing conditions, up to 32 approved factual claims and 32 claim limits, plus the business introduction and screening line. Explain what is known and unknown; never invent results or a prior relationship. Knowledge supplies the live helper and private practice with facts, while the helper generates its own wording. It is not an exact-sentence allowlist. The separate set-script template controls advance preparation.

Each publication records its reason and previous version, retaining history. A stale form cannot overwrite a newer review. If publication loses its response or refresh fails, use **Reload current knowledge** to read the saved version before editing again. A published change withdraws obsolete live advice through the existing event channel and invalidates preparation for future calls. The active script remains stable; it is not rewritten during speech. These changes are not yet in released 0.2.1.

Use keyword trackers for literal phrases and semantic trackers for a defined concept with positive/negative examples and transcript citations. Preview changes on a frozen reviewed set. A semantic hit is rejected if its evidence does not exist. Human notes remain separate from AI revisions; a conflicting human edit requires review.

The scorecard uses call-purpose anchors, N/A and INSUFFICIENT_EVIDENCE and shows its denominator/coverage. A short wrong-number call cannot become a poor discovery score. Team associations are correlations. Reviewers can challenge scores and publish reviewed paraphrased examples with source versions; corrections and withdrawals remove obsolete examples from retrieval. Raw evidence expires within five minutes. Retained examples must not be copied transcript excerpts. Review also contains personal practice goals and private practice that creates no call or business outcome.

`packages/evaluation-fixtures/coach.jsonl` is explicitly synthetic. The evaluation command defaults to OpenRouter/Cerebras and requires `OPENROUTER_API_KEY` in a protected environment: `uv run python scripts/evaluate_coach.py --output work/coach-benchmark.json`. It makes paid inference requests only when deliberately run with credentials. The legacy fixture's action/card checks do not certify freeform semantic quality. Add novel-context replays and balanced human usefulness review before asserting complete model quality, end-to-end latency or improved outcomes.
